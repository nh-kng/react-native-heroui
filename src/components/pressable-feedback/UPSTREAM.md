# pressable-feedback provenance

The native adapter wraps the owned HeroUI Native `src/components/pressable-feedback/` implementation at `1980fbbbd6e8112cf9363614abec683379e89da3`. No later revision has been reviewed or incorporated.

The web adapter is local code using the public React Aria Button API. HeroUI React has no corresponding PressableFeedback component. Browser feedback uses shared native-origin classes with additional browser selectors in `styles/web-only.css`.

Shared animation controls expose boolean and disabled states; granular native animation configurations and native `asChild` are outside the shared contract. Web feedback is inspired by the documented [HeroUI Pro Pressable Feedback](https://heroui.pro/docs/react/components/pressable-feedback) behavior without importing Pro code or adding a dependency. Web Ripple expands from the pointer position, or the center for keyboard and virtual activation; native Ripple retains the owned touch-origin implementation. Web manages decorative surfaces inside an otherwise empty React-owned container to avoid animation-driven React state updates. It uses independent Web Animations API expansion and opacity tracks with size-aware timing, overlapping surfaces, and shorter cancellation fades; it does not reproduce Native Reanimated timing defaults or share granular animation configuration. Existing web CSS timing overrides remain supported, with additional timing and easing variables documented in the component API. Root refs remain platform-specific. See the [component API](../../../docs/api/components.md#pressablefeedback) and [owned source map](../../../docs/upstream/owned-source-map.json).

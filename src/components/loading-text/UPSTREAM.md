# LoadingText provenance

LoadingText is an original adapter-only component. It is inspired by the [HeroUI React Skeleton](https://heroui.com/en/docs/react/components/skeleton) and [HeroUI Native Skeleton](https://heroui.com/en/docs/native/components/skeleton) animation conventions, but does not copy their placeholder renderers or expose their private APIs.

Native uses the repository's owned theme, text, direction, and animation-settings helpers, Reanimated, react-native-svg, and the public MaskedView API. Web uses a CSS gradient clipped to text. There is no corresponding upstream HeroUI React example inventory.

# Example gallery instructions

- For every implemented component, follow the contents of its page linked from [HeroUI React components](https://heroui.com/en/docs/react/components), including Usage, all Examples, and Customization previews. The example catalog records the preview IDs and order from those pages; TextArea and TextField demo source folders use `textarea` and `textfield` respectively.
- Inspect the corresponding upstream demo source before changing a preview. Keep its composition, sample content, states, and advertised interaction recognizable while adapting HTML layout to React Native and upstream names to this package's public API.
- Consume `@nh-kng/react-native-heroui` public exports. Do not import installed HeroUI components, package internals, or upstream demo modules into the gallery. Use typed `webProps` and `nativeProps` for platform differences; do not widen the adapter contract or use casts solely to make an upstream demo compile.
- Keep related previews together under `gallery/docs-examples/`. Reuse a renderer only when explicit configuration preserves each preview's distinct behavior. A title and default component alone do not implement a variant, validation, loading, or interaction example.
- Record unsupported upstream APIs by preview ID in `gallery/docs-examples/limitations.ts`, with the precise missing contract. Show those differences on the component page. Explain partial platform adaptations in `gallery/docs-examples/notes.ts`; keep simulations and unconnected service integrations clear to users.
- Keep controls operable with local state, include validation recovery, preserve associated labels and descriptions, and avoid browser globals in shared modules. Use inline text or SVG in icon slots rather than paragraph elements.
- Maintain [gallery coverage](../docs/development/component-examples.md) when coverage changes. Verify using `node --test tests/gallery-examples.test.mjs` from the repository root and both example TypeScript export conditions. Do not start previews, run browser tests, or use devices unless explicitly requested.
